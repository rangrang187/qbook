# V5 实验设计与冻结记录

本轮在已实现的 V0～V4 上开发真实实验，不改变业务契约。前置本轮 Debug 完整测试已于 2026-10-27 实际执行：167/167 通过。正式实验结果另见 `V5-results.md`，历史 V4 结果不充作本轮证据。

## 环境与资源

当前目录 `/mnt/d/Desktop/unsw/qbook`，开发容器 Linux x86-64，WSL2 内核 `6.6.87.2-microsoft-standard-WSL2`，glibc 2.39；Intel Core i7-13650HX，容器可见 20 个逻辑 CPU、约 12.4 GB 内存，初始可用磁盘约 43.7 GB。输出介质是该仓库所在 D: 的 9p/DrvFS 挂载。未固定 CPU 亲和性、频率或宿主后台负载，不清系统缓存，因此结论仅适用于记录的环境。

编译器 GCC 13.3.0，CMake 3.28.3，Ninja 1.11.1。正式构建为 Release、IPO/LTO OFF；保留实际编译数据库及链接审计摘要。Arrow/Parquet 开发包和共享库为系统 `/usr` 的 26.0.0-1，CMake EXACT 26.0.0，ZSTD 1.5.5。qlib、Catch2、fkYAML、spdlog、libzmq、cppzmq 均沿用固定源码，六份清单实际核验通过。

当前容器没有历史记录中的 Node 安装。本轮从官方归档恢复同一 Node 24.22.1，下载 SHA-256 同时匹配官方 SHASUMS 和 V4 记录；未升级 UI 锁定依赖。第一次下载超时，续传后校验通过。工具链、npm 和浏览器实际执行版本在最终验收记录补充。

每轮输入预算 256 MiB、输出预算 1 GiB；实现对整数乘加、输入数量和可用空间做受检运算。Writer 输入最多 100 万条。正式性能与编译、其他性能工作串行。当前环境未发现 `perf`，硬件热点采样暂为 N/A，不修改权限或系统策略。

## 实验矩阵

规范参数保存在 `benchmarks/config/V5-baseline.yaml`，seed=20261027。起始矩阵 53 个 case：核心 22、协议 12、Writer 13、Pipeline 6。每个正式 case 独立预热 1 轮、测量 5 轮；每轮重新建立初态，原始慢轮与无效轮全部保留。试跑完成后在此记录冻结标识；任何参数变化使用新实验身份。

| 系列 | 问题与初态 | 输入与规模 | 独立核对 |
|---|---|---|---|
| core.add | 增长分配及新价位成本；空簿 | 8192 次新增，16/8192 档 | ID、数量、FIFO、价档、不变量、快照、输入不变 |
| core.modify | 同价、已存在价位、新价位修改；1024/8192 活跃订单 | 65536 次稳态更新；新价位1024次；16/256档 | 每次应执行的 Applied/Ignored 及最终完整状态 |
| core.cancel/trade | 部分扣减与真实销毁；新建指定初态 | 部分65536次、全删1024/8192；双侧成交512次 | 不退化成未知ID；双侧及FIFO关系独立期望 |
| core.l2 / ignored | L2绝对覆盖/删除/成交，以及业务忽略成本 | 固定64档；65536更新或64删除；明确忽略原因 | L2无虚构订单，忽略不改变业务状态但更新时间 |
| core.snapshot | 空簿、非空簿、多品种遍历 | 1/32品种；全部品种合计1024订单；固定调用数 | 每品种最优一档及时间字段 |
| protocol | 四类合法帧、五类拒绝及固定混合比例 | 131072次解码；256/4096帧工作集 | 独立golden、字段、错误分类、输入不变 |
| writer | 五类列追加、压缩、尾批与批量差异 | 单类型8193条；混合各2049；B=1024/16；0/B−1/B/B+1/2B+1 | 五个真实文件全部chunk、schema、元数据、ZSTD、整数、同类型顺序 |
| controlled-queue | 排除网络后的接纳、处理、写入与排空 | Mbo/L2，2品种，有限1024事件；真实Book/Writer/Metrics | 成功push账本逐条对应正常关闭文件 |
| network-finite | 真实网络四阶段有限完成与停止 | XPUB订阅就绪后1024事件；真实RunServiceImpl | 发送/解码/接纳分开；原事件及快照读回 |
| network-steady | 固定工作集在规定速率下是否保持稳定 | 1024事件/秒，2秒预热+3秒正式+1秒保护；Mbo同价交替数量/L2绝对交替量 | 全部窗口速率、积压估计、累计漂移、迟到、窗口数和最终文件 |

稳态采样200ms，至少3个连续窗口；相对速率容差0.25，单窗与全正式阶段积压漂移上限64，两个积压估计上限128，发送/采样迟到上限50ms，期限30秒。这些为冻结的实验有效性条件，不是产品性能达标线。计数采样非事务，F−B/B−W只是带符号积压估计，可小幅为负；不能解释成精确队列长度。正式窗口全部检查，边界窗口保留但不当完整窗口，不能挑最好窗口。

## 计时与分母

| 阶段 | 计时边界 | 分母 |
|---|---|---|
| 核心/协议 operation | 输入与初态完成后，批循环起止；分类/checksum计入 | 实际调用数；快照为实际品种快照调用数 |
| Writer open | 构造前至构造成功 | none / 0 |
| Writer add | 构造成功至全部Add成功，含变体分发与触发批次刷新 | written_records / N，零行none |
| Writer close | 全部Add后至显式Close成功，含尾批/footer | none / 0 |
| Writer total | 构造前至Close成功 | written_records / N，零行none |
| 受控 input-admission | 首次测量push前至末次成功push后 | accepted_events / N |
| completed-window | Writer首条至末条测量原事件Add成功 | completed_intervals / N−1 |
| finite/completed-cycle | 各自进程内的开始/完成观察边界，具体见manifest | 本系列声明的完成原事件数 |
| steady-input-window | 父进程预先冻结的正式发送窗 | sent_events / N |
| steady-tail-completion | 保护窗结束至父方观察全部原事件完成 | none / 0 |
| drain / shutdown | 同一协调线程的StopObserved及各阶段join时点 | none / 0 |

父/worker时钟不相减。观察器只在各阶段首末原事件取时，快照不计入原事件目标；生命周期观察为私有固定冷路径hooks。生产 qbook 默认hooks为空，没有Feed逐事件探针。每轮必须Close及join后独立读回，Add达到目标不足以判有效。输入、初态、校验、析构放在各自声明区域，不能把批均值称为事件P99。

## 证据格式及试跑规则

每次运行排他创建目录；manifest记录dirty源码内容摘要、Git基线、二进制与构建缓存摘要、工具链、依赖、规范配置、工作负载FNV-1a64、全部预热和正式轮次。FNV是内容标识，不是密码学完整性保障；依赖固定仍使用SHA-256。失败保留证据，不重试结果不明的写批次。

用户要求固定16列，但计划§3.1.2.2原表只列15项。本轮保留原15项顺序，补第16列 `validation_message`，记录无效原因或时钟分辨率说明；该差异同步到计划。

先全部smoke确认真实路径，再做预试跑评估资源与时长，最后冻结正式参数。配置冻结后的无效轮不能通过放宽容差改成通过。分析器使用精确整数和分数，只汇总完整、有效的正式轮次；smoke/profile/invalid分开。OI-04绝对门槛保持待定。

## 初态参数的精确解释

`initial_orders` 是整轮全部品种的被测订单数，`levels` 是生成器的候选价格宽度，不能一律解释成每簿订单数或实际总档数。冻结负载不因文档修正而改变：

- 单品种 Mbo 同价修改1024/8192订单、levels=16：买卖各16档；many_levels=256时买卖各256档。
- existing_price另有4张不参与修改的锚定单，实际初态1028张；它们保证目标价位已经存在。
- 空簿增长levels=16的买卖与价格交替关联，实际总16档；L2 levels=64是总64档、每侧32档。
- snapshot单品种1024订单、每侧16档；snapshot.many把总1024订单分到32品种，每簿32订单。品种与价格模数相关，每簿买卖各1档；不能把两者当成相同簿密度的扩展对照。
- snapshot.many每轮4096次品种遍历，共131072次快照调用；单调用和32品种轮次是同一测量的两种分母，不能当独立样本。

正式执行固定按core→protocol→writer→pipeline、配置中的case顺序，每case先独立预热再5轮；未随机打乱、未清页缓存。计时包含声明的状态分类、摘要及循环成本。较短内核和文件系统抖动的范围如实保留，不据批均值推导单事件尾延迟。
